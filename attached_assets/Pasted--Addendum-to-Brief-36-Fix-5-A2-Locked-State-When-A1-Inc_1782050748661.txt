## What & Why

When A1 (All In It) is not fully complete, A2's Mirror 1 (Alignment Check) card is in a contradictory state: it shows the "UP NEXT" badge (signalling "this is available, go here") while its CTA button is greyed and disabled with body text "Complete A1 to begin." This is a dead/greyed CTA, which violates the locked rule: a dead/greyed button is never acceptable — it must name the next action and route there.

The correct behaviour must mirror how A1 itself already works (verified live): when a mirror is claimed, the claim CTA **names the next mirror** ("Continue to Values →") and routes the user to the **hub** (the card grid), where the next mirror shows as the active "Up Next" with a live begin button. The pattern is: **name the destination, route to the hub.** A2's locked state must follow this same pattern.

## The gating rule (confirm this is what's implemented)

A2 is locked in its entirety until A1 is complete (all four A1 mirrors claimed: Purpose, Vision, Identity, Values). When A1 is incomplete:
- M1 Alignment Check is LOCKED (not "Up Next")
- M2 Time Audit is LOCKED
- M3 Named Truth is LOCKED

A2 only becomes enterable once A1 reads 4 of 4 claimed.

## Done looks like

When A1 is NOT complete, the A2 hub cards read:

- **M1 Alignment Check** — badge: **LOCKED**. Body names the specific remaining A1 gap, e.g. *"Finish All In It first — one Mirror left: Values · The Order You Live By."* If more than one A1 mirror is incomplete, name the next incomplete one in A1's order (Purpose → Vision → Identity → Values). CTA button: **live and active**, reads **"Go to All In It →"**, routes the user to the **A1 hub** (the four-card grid) — NOT directly into a mirror's exercises. This matches A1's claim-routing pattern: name the destination, land on the hub.
- **M2 Time Audit** — **LOCKED**. Body: *"Unlocks after Alignment Check."* (unchanged)
- **M3 Named Truth** — **LOCKED**. Body: *"Unlocks after Time Audit."* (unchanged)

When A1 IS complete (4 of 4 claimed):
- **M1 Alignment Check** flips to **UP NEXT** with a live **"Begin Alignment Check →"** button. Normal A2 sequence resumes.
- M2 and M3 follow their existing unlock-on-prior-claim logic.

The key change: **M1 must never show "UP NEXT" with a dead button.** It is either LOCKED with a live "Go to All In It →" button (A1 incomplete), or UP NEXT with a live "Begin Alignment Check →" button (A1 complete). No third state.

## How to determine "the next incomplete A1 mirror"

Read A1 completion state. Walk A1's mirrors in order (Purpose, Vision, Identity, Values) and name the first one not claimed. Display that name in the M1 locked-card body. On this test profile, Purpose/Vision/Identity are claimed and Values is not — so the body should name **Values**.
