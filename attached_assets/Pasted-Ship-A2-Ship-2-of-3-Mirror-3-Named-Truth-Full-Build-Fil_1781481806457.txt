What M3 Does

M3 (Named Truth) takes everything the user logged in M2 and turns it into decisions and a commitment. Three steps:


The gap — auto-calculated from M2 data. No new input. Just the mirror.
Rethink your time — decisions on every activity (Move it / Reduce it / Cut it / Do it) + trade freed hours into missing items or more priority time.
Claim — summary + Self Feedback + Katherine seal + gold burst.



State Schema — writes to to_a2_state_v1.m3

typescriptm3: {
  // Step 2 decisions
  activityDecisions: {
    [activityId: string]: {
      decision: 'move' | 'reduce' | 'cut' | 'do',
      newHrs: number | null,   // null = use original. 0 = cut.
      who: string,             // who/what takes the rest (move or reduce)
    }
  },

  // Step 2 trade panel
  missingAssignments: {
    [missingItemId: string]: number   // hrs assigned to this missing item
  },
  priorityCommitments: Array<{
    priority: string,          // matches a priority name from m2.priorities
    addedHrs: number,
    activity: string,          // what they'll do with the time — carries to A4
  }>,

  // Step 2 move text
  moveText: string,            // auto-generated, user-editable

  // Step 1 intent
  intentMap: {
    [priorityName: string]: 'yes' | 'no' | 'unsure'
  },

  // Self Feedback
  selfFeedback: string,        // cached API response

  // Claim
  claimed: boolean,
  claimedAt: string | null,
}

Step 2 — Rethink Your Time

Eyebrow: A2 · MIRROR 3 · STEP 2
Title: Rethink your *time.*
Lead: "Your week, laid out. Change what needs changing — leave the rest."

Default note (gold-tinted card at top)

"You don't have to go through all of this. If an activity is fine as is, leave it — the system keeps your original hours. Only act where something needs to change."

Freed hours counter (hero display)

Gold card, always visible, updates live:


Large Georgia serif number (gold, ~38px): total hours freed so far
Label: "hrs freed this week" (or "hrs freed so far" when 0)
Recalculates on every decision change


Freed hours calculation:

freed = sum over all activities of (originalHrs - effectiveHrs)
effectiveHrs = 
  if decision === 'cut': 0
  if decision === 'move' or 'reduce' AND newHrs !== null: newHrs
  else: originalHrs (default)

Accordion groups

Four groups. One open at a time — tapping a header opens it and closes the others. Despise opens first by default.

Each accordion header shows:


Group label (coloured by feel)
Activity count · total original hrs
Hours freed from this group (updates live as decisions are made)


Groups:


Despise — highest cost (#A03B3B label colour) — activities where feeling === 'despise'
Dislike — worth a look (burgundy label) — activities where feeling === 'dislike'
No priority — serving nothing named (muted label) — activities where priorityServed === '' AND feeling is not despise/dislike
Everything else — confirm or keep (green label) — activities where priorityServed !== '' AND feeling is not despise/dislike


If a group has 0 activities, skip it entirely (don't render the accordion).

Activity cards (inside accordions)

Each activity from m2.activities[] appears in exactly one group.

Card layout:


Top row: activity name · feeling badge (colour-coded) · priority badge (gold if tagged, muted if none) · original hrs
Decision buttons (4, equal width):

→ Move it / Someone else or automate — gold when selected
↓ Reduce it / Do less of it — amber when selected
✕ Cut it / Remove entirely — burgundy when selected
✓ Do it / Keep as is — green when selected, pre-selected by default



Detail panel (appears below buttons when Move or Reduce selected):

Row 1: "Your hrs / week" · number input (0 to originalHrs) · shows "+X hrs freed" when filled
Row 2: "Who / what takes the rest" · text input · placeholder "e.g. Leighann, VA, automation…"



Suggestion (italic muted text, shown for Despise/Dislike/untagged activities):

Generated contextually. Examples:

High hrs + despise + no priority: "[N] hrs of [activity] with no priority attached — strong candidate for delegation or elimination."
Dislike + serves priority: "You dislike this but it serves [Priority]. Can you reduce it or restructure how it gets done?"
Love + no priority: "You love this — it just wasn't tagged. Tag it and protect it."








Saves to m3.activityDecisions[activity.id] on every change.
