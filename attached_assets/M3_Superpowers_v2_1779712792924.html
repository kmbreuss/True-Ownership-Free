WHAT'S NEW · WHAT STAYS

What stays from the current Replit build: Room header (eyebrow, title, subhead, help card). Auto-clustering on entry. The three suggested cluster cards with editable cluster name, animal row (emoji + 2 descriptors + animal name + browse), gifts-this-creature-carries chip bin. Tap-a-gift-to-move-it behavior between clusters. × remove cluster.

What's new — three additions:

1. Inventory bar (sticky at top). Shows all picked gifts grouped by theme with theme colors. Gifts assigned to a creature render in gold-filled state. Unassigned gifts render in theme-tinted outline. Every theme row has its own "+ add" button — user can add a gift to any theme.

Add behavior: Gifts that came from Step 1a (Your Gifts) are auto-assigned to clusters by the archetype-matching system (existing behavior). Gifts added on Superpowers via the "+ add" button on any theme row are manually placed — a small "Which creature carries this?" picker appears, user picks the cluster, gift lands there. Newly added gifts flow back into Step 1a's record so Step 1a stays in sync.

Move behavior: Any gift (auto-assigned or manually added) can be moved any time. Tap the chip from either surface — the inventory bar at top OR inside a cluster card — and the same "Which creature?" picker appears. Pick the new cluster, gift moves.

2. Superpower sentence at the bottom of every cluster card. Gold register. Three blanks: "In my power, the {animal} [what I do well], [what it gives me], and [what it gives others]." Same three-blank architecture as Under Pressure's shadow sentence, opposite tone. Required for Continue.

3. "+ Add another creature" button below the cluster stack. Cap at 5. Creates a new empty cluster card the user can fill in (cluster name, animal via browse modal, then taps gifts in the inventory bar to move them in). Default emoji ✨ until user picks one.
