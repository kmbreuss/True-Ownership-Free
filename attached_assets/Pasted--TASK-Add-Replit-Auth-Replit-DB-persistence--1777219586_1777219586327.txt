SCOPE OF THIS PASS (additive only)
═══════════════════════════════════════════════

A. AUTH
   - Add Replit Auth (Google + email magic link, whichever is simplest
     to enable in this Replit project).
   - Login screen appears BEFORE the app loads if user is not
     authenticated.
   - "Sign out" link in the existing top-right header (next to the
     Katherine name slot, or wherever fits the existing layout).
   - Authenticated user object exposes at minimum: userId, email, name.

B. DATA MODEL (Replit DB)
   - One DB record per user.
   - Key shape: `user:{userId}:map`
   - Value: the existing `map` object (the same shape currently
     serialized to localStorage under KEYS.map / "to_map").
   - Also store: `user:{userId}:voice` (KEYS.voice equivalent).
   - Also store: `user:{userId}:mapofme_origin` (the
     to_mapofme_origin equivalent).
   - All writes happen on the existing 800ms debounced saveMap, plus
     on every voice change and every mapofme_origin change.

C. READ PATH
   - On app load, after auth: read DB first.
   - If DB has data for this user: hydrate React state from DB. Done.
   - If DB has NO data for this user: check localStorage. If
     localStorage has data, this is a returning beta tester — go to
     migration flow (D).
   - If neither exists: brand new user, start from empty state as today.

D. MIGRATION FLOW (one-time, per user)
   - Trigger: user logs in, DB has no record for them, localStorage
     has data.
   - Show a one-time modal:
       Title:  "We found your existing answers on this device."
       Body:   "Bring them with you so they're saved to your account
                and accessible from any device?"
       Buttons:  [Bring them with me]   [Start fresh]
   - "Bring them with me":
        1. Read map, voice, mapofme_origin from localStorage.
        2. Write all three to DB under this userId.
        3. Set a flag `user:{userId}:migrated = true` in DB.
        4. Hydrate React state from the just-written DB values.
        5. Close modal.
   - "Start fresh":
        1. Set `user:{userId}:migrated = true` in DB (so we don't ask
           again).
        2. Do NOT clear localStorage (keep it as a fallback).
        3. Hydrate from empty state.
   - The modal NEVER appears again for this user once `migrated` flag
     is set.

E. WRITE PATH
   - Wherever the existing code calls localStorage.setItem(KEYS.map, ...)
     also call dbSet(`user:${userId}:map`, ...).
   - Same for KEYS.voice and to_mapofme_origin.
   - Failures to write to DB should be logged to console but should
     NOT block the localStorage write or break the UI.
   - The 800ms debounce on saveMap stays as-is.

F. ADMIN VIEW (out of scope for this pass)
   - Do NOT build an admin view in this pass. We'll do that separately.
