**Why native presentation matters:** The owner explicitly rejected Map edit destinations that did not look like the normal mirror rooms. Verify paired screens reached through both entry paths, not just the underlying fields.

**Why:** Mirroring the selected area into child state through an effect briefly showed one area's heading above another area's saved fields during desktop verification.

**How to apply:** Use the same UI-only target for the native frame and its answer adapter. Do not duplicate it into effect-synchronized state or persist it as account progress.

**Why:** The owner explicitly chose retirement rather than historical display or new authoring.
