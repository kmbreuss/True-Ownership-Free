name: App copy boundaries
description: Commitment terminology, saved-answer protection, and the Vision desktop heading size floor.
---
Use commit/commitment language instead of “keep your word” in app-authored copy. This is a copy change, not a data migration: user-written answers must remain exactly as entered, even when they contain the old wording.

**Why:** The owner requested a product-wide terminology change while explicitly protecting everything users have written.

**How to apply:** Edit static labels, instructions and generated framing only. Preserve route IDs, storage keys and technical fields; retain old phrases in test fixtures when they represent user-authored text.

For the Reality Check-linked Vision opening, use the card's available width before reducing type. Desktop headings must not go below 26px; wrapping is preferable to shrinking below that floor. The existing phone heading override remains unchanged.

**Why:** The owner explicitly prioritized readable desktop type over forcing a one-line result.

**How to apply:** Keep the adjustment specific to this heading, test the longest area name, and report wrapping instead of clipping or reducing text below the desktop floor.
